# GlobeCopy

**AI 跨文化营销本地化助手**

GlobeCopy 面向有海外推广需求的商家与内容运营人员，将中文商品文案改写为适合目标市场语言习惯的营销内容，并提供中文对照和文化适配说明，帮助用户理解每一次表达调整。

## 核心功能

### AI 营销文案本地化

输入商品名称和中文营销文案，选择目标市场，即可生成一版完整结果：

- **本地化营销文案**：围绕商品卖点调整措辞、语气和句式。
- **中文对照**：对应生成后的外语文案，方便理解和核对。
- **文化适配说明**：解释本次表达调整及其原因。

生成要求保留价格、规格、日期和优惠条件等商品事实。

### 三个目标市场

| 目标市场 | 对应语言 |
| --- | --- |
| 美国 | 英语（美国） |
| 日本 | 日语 |
| 德国 | 德语 |

目标语言随国家自动匹配，方便比较同一商品在不同市场的表达方式。

### 使用自己的模型 Key

支持 **DeepSeek、硅基流动（中国区）和 OpenRouter**。用户选择供应商，填写具备 JSON 输出能力的模型 ID 和自己的 API Key；服务地址固定展示。

### 免 API 演示体验

无需填写 Key，即可体验 **两种商品场景 × 三个市场，共 6 组演示**：

- **便携保温杯 · 日常推广**：展示通勤场景、商品卖点与不同语言的表达调整。
- **桌面收纳盒 · 限时促销**：展示数量、价格、活动日期和优惠条件的完整表达。

选择场景与市场后，页面同时呈现中文原文、本地化文案、中文对照和适配说明。

### 结果复制与操作反馈

- 一键复制本地化文案，提供成功反馈和失败时的手动复制提示。
- 输入校验与字符计数，帮助发现空白或超长文案。
- 生成期间展示加载状态，防止重复提交。
- 请求失败时保留输入，提供错误说明与手动重试。
- 修改文案或切换目标市场时清除旧结果，避免内容错配。

## 适用场景

商品出海推广、跨境电商内容创作、海外营销文案初稿，以及跨文化表达的学习与演示。
