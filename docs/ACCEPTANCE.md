## 三、剩余人工验收

先执行：

```powershell
npm --prefix frontend run build
npm --prefix backend start
```

打开后端地址，默认为 `http://127.0.0.1:3001`。保留已有后端环境配置；若端口被占用，先停止之前的开发服务。

- [ ] 笔记本和窄屏布局：表单、错误横幅、长文本、复制按钮没有遮挡或明显横向溢出。
- [ ] 键盘操作：可以用 Tab 到达主要操作，焦点可见；字段错误与对应输入关联。
- [ ] 生成中不能修改输入或重复提交，完成后恢复操作；编辑输入、切换国家和填入样例都会清除旧结果。
- [ ] 复制后粘贴到文本编辑器，内容与外语文案完全一致，不含标题、中文或说明；复制失败有手动复制反馈。
- [ ] 服务失败后输入保留，错误提示可关闭，用户点击重试才会再次请求。
- [ ] 浏览器业务请求仅发往本机 `/api`，不携带模型密钥；模型文案中的 HTML 以文本展示。
- [ ] 美国、日本、德国各生成一次，检查语言、主要卖点、中文对照和适配理由。
- [ ] 数字与条件样例检查价格、币种、数量、日期和优惠条件，无新增无依据的功效或认证。
